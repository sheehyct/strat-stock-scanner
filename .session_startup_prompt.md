## Required Environment Variables (post-Tradier migration)

These MUST be set both in the Railway dashboard for production and in `.env`
for local development. The names below match `config.py` exactly (Pydantic is
case-sensitive). Do NOT commit `.env`.

| Variable | Purpose | Default |
|----------|---------|---------|
| `TRADIER_API_TOKEN` | Tradier Market Data bearer token (required) | none |
| `TRADIER_USE_SANDBOX` | `true` routes to sandbox.tradier.com | `false` |
| `TRADIER_SANDBOX_TOKEN` | Sandbox token (required when `USE_SANDBOX=true`) | none |
| `JWT_SECRET_KEY` | OAuth 2.1 JWT signing key (rotate on leak suspicion) | none |
| `OAUTH_CLIENT_ID` | OAuth 2.1 client registration | `claude-mcp-client` |
| `OAUTH_CLIENT_SECRET` | OAuth 2.1 client secret | none |
| `SERVER_URL` | Used in `/.well-known/oauth-protected-resource` to advertise the resource URL to MCP clients. **MUST match the Railway domain that serves traffic** | `http://localhost:8080` |
| `PORT` | Railway binds this; do not hardcode | `8080` |
| `LOG_LEVEL` | `INFO` for prod, `DEBUG` for local diagnosis | `INFO` |
| `RATE_LIMIT_PER_MINUTE` | Tradier-side throttle ceiling | `100` |
| `MAX_CONCURRENT_REQUESTS` | Concurrency cap | `4` |

Alpaca variables (`ALPACA_API_KEY`, `ALPACA_API_SECRET`, `ALPACA_BASE_URL`,
`ALPACA_DATA_FEED`, `ALPACA_REQUESTS_PER_MINUTE`) are no longer used. Remove
them from local `.env` and Railway. The Alpaca API key was rotated/deleted
on 2026-05-22 as defense-in-depth (was exposed in `.env.test` git history
before the migration deleted that file).
