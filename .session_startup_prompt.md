## Follow-up PRs queued (pick what's most valuable)

Listed in approximate priority order, all independent of each other:

### 1. OAuth client validation (security tightening)

`auth_server.py:109-291` accepts arbitrary `client_id`,
`redirect_uri`, and `client_secret` without validating against
`settings.OAUTH_CLIENT_ID` / `settings.OAUTH_CLIENT_SECRET`. Anyone
who knows the server URL can mint valid JWT bearer tokens.

Realistic risk is bounded (URL not publicized, no PII, no order
placement), but worth tightening before any future broadening of
usage. Open a focused PR. **Test against the live claude.ai OAuth
client_id** to ensure validation does not break the integration -
otherwise you will be debugging two things at once.

Approach:
- Validate `client_id == settings.OAUTH_CLIENT_ID` at `/authorize`.
- Validate `redirect_uri` against an allow-list (start permissive
  matching claude.ai's actual redirect URL, then tighten).
- Validate `client_secret == settings.OAUTH_CLIENT_SECRET` at
  `/token` when provided.
- Return RFC-6749 spec errors for failed validation, not opaque
  500s.

### 2. Typed provider errors

`tradier_client._request` returns `None` for every failure mode (auth,
rate limit, network, vendor 5xx, no-data). `mcp_tools.py` collapses
that to "No data available" or empty patterns regardless of cause.
A user seeing "symbol unknown or upstream error" cannot tell whether
their ticker is wrong or the API is down.

Approach:
- Define a `TradierError` exception with a `category` field
  (`auth_failed`, `rate_limited`, `network`, `vendor_5xx`,
  `unparseable`, `no_data`).
- Raise it from `_request` instead of returning `None`.
- `mcp_tools.py` catches and surfaces category in the user-facing
  response (e.g., "Service temporarily unavailable" vs "Symbol
  not found").
- Update tests to assert the right category for each error path.

### 3. Architecture / performance

Two small wins worth bundling into one PR:

- **Process-lifetime `httpx.AsyncClient`**: currently
  `tradier_client._request` creates a new `AsyncClient()` per call,
  losing connection pool reuse. A 30-symbol sector scan does 30+
  TCP handshakes. Move to a module-level client, ensure it is closed
  at app shutdown.
- **Rate-limiter semaphore release before backoff**:
  `rate_limiter.py:66-105` holds the semaphore slot during retry
  backoffs. With `max_concurrent=4`, one slow ticker can pin a slot
  for 10+ seconds. Release before backoff, reacquire after.

## Required Environment Variables (reference)

Names below match `config.py` exactly (Pydantic is case-sensitive).
Do NOT commit `.env`. Required on Railway and in local `.env`:

| Variable | Purpose | Default |
|----------|---------|---------|
| `TRADIER_API_TOKEN` | Tradier Market Data bearer token (required) | none |
| `TRADIER_USE_SANDBOX` | `true` routes to sandbox.tradier.com | `false` |
| `TRADIER_SANDBOX_TOKEN` | Required when `USE_SANDBOX=true` | none |
| `JWT_SECRET_KEY` | OAuth 2.1 JWT signing key | none |
| `OAUTH_CLIENT_ID` | OAuth 2.1 client registration | `claude-mcp-client` |
| `OAUTH_CLIENT_SECRET` | OAuth 2.1 client secret | none |
| `SERVER_URL` | Used in OAuth discovery; MUST match Railway domain | `http://localhost:8080` |
| `PORT` | Railway binds this; do not hardcode | `8080` |
| `LOG_LEVEL` | `INFO` for prod, `DEBUG` for local diagnosis | `INFO` |
| `RATE_LIMIT_PER_MINUTE` | Tradier-side throttle ceiling | `100` |
| `MAX_CONCURRENT_REQUESTS` | Concurrency cap | `4` |

**Important:** Pydantic enforces RFC 7230, so the bearer token must
not have leading/trailing whitespace. `tradier_client.__init__` strips
defensively as of `30158d3`, but still worth pasting cleanly.

Alpaca variables are no longer used. The Alpaca API key was rotated/
deleted on 2026-05-22 as defense-in-depth.
