## Expected Environment Variables

These MUST be set in the Railway dashboard for production, and in
`.env` for local development. Do NOT commit `.env`.

| Variable | Purpose |
|----------|---------|
| `ALPACA_API_KEY` | Alpaca SIP feed credential (until Tradier ships) |
| `ALPACA_SECRET_KEY` | Alpaca SIP feed credential (until Tradier ships) |
| `ALPACA_PAPER` | `true` or `false` - paper vs live data tier |
| `TRADIER_TOKEN` | Tradier sandbox/production token (Tradier migration) |
| `TRADIER_BASE_URL` | `sandbox.tradier.com` for dev, `api.tradier.com` for prod |
| `JWT_SECRET` | OAuth 2.1 JWT signing key (rotate on leak suspicion) |
| `OAUTH_CLIENT_ID` | OAuth 2.1 client registration |
| `OAUTH_REDIRECT_URI` | OAuth 2.1 callback URL |
| `PORT` | Railway binds this; do not hardcode |
| `LOG_LEVEL` | `INFO` for prod, `DEBUG` for local diagnosis |

If a fetch errors with "credentials not configured," check the Railway
dashboard before debugging code paths.
